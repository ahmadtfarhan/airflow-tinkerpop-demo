# airflow-tinkerpop-demo

## Branches

- `tinkerpop-demo-101`: Minimal setup and beginner-friendly Airflow DAGs that walk through the basics of extracting from MySQL and loading into Gremlin.
- `meetup-demo`: Advanced demo branch with a richer DAG setup, additional tasks, and configuration meant for live presentations or meetup sessions.
- `demo-summit-2026`: Airflow Summit 2026 talk branch. Builds a knowledge graph and a vector index from the same corpus and scores a graph-agent, vector-RAG, and full-context arm against ground truth, to show when graph traversal beats retrieval.
